# Simple PDF Converter

Turn photos of any document into a single PDF and save it to your phone.
Everything runs in the browser; no photo is ever uploaded.

- One file per document type (Result Cards, Roll No Slips, Certificates, ...)
- Tag every page with its class; the PDF stamps the tag on each page
- Camera or gallery input, quality enhancement, A4 or fit-to-image pages
- Works offline once opened; add it to your home screen

Static site: `index.html` at the repository root, no build step.
